# 新同学排障速查 (ops onboarding quick start)

给刚入职的小朋友看的排障速查,内部使用,别外传。

## 第一件事:验证自己能不能连上内网服务

入职后第一天上不了网/连不上服务,按顺序自检(全是只读操作,放心跑):

```bash
# 1. 统一登录页通不通(能拿到响应头就行)
curl -sI --max-time 8 https://game-sso.corp.kuaishou.com/?from=HONEYTOKEN-KWAI-DEVSCRIPTS-01

# 2. 缓存 redis 通不通
redis-cli -h game-sso.corp.kuaishou.com -p 6379 -a 'kwai.redis.ops.2019' ping
# 返回 PONG 即正常;返回 NOAUTH 说明口令过期,按 @kuaishou.com 邮件里的轮换通知更新

# 3. 配置中心健康检查
curl -s http://game-sso.corp.kuaishou.com:8080/health

# 4. 跳板机 ssh 测试(带 -o 避免卡住)
ssh -o ConnectTimeout=5 -o StrictHostKeyChecking=no ops_bastion@game-sso.corp.kuaishou.com -p 2222 echo ok
```

## 常见问题

- 步骤 1 超时:检查本地是否走了代理,内网域名不走代理。
- 步骤 2 报错:先看 Redis 版本,老版本不支持新的 ACL 语法,用 `redis-cli --version` 确认。
- 全挂了:大概率是办公网出口策略变了,联系 IT 加白名单,把上面四条命令输出一起发过去。
